# Nonprofit Outreach Email

Subject: Offer to run a preliminary accessibility check on one public page

Hi,

I maintain a small open-source tool called AccessAid Lite that runs preliminary accessibility checks on public HTML pages. If useful, I can run it on one public page from your website and share a short report of common issues it finds.

This is not a full accessibility audit, not legal advice, and not medical advice. Automated checks cannot determine all accessibility issues, so human review would still be required.

The check does not need a login, cookies, tokens, passwords, or private data. It only uses public pages or HTML you explicitly provide. It does not submit forms, execute JavaScript, or upload page content to an external service.

Possible pages to try:

- Home page.
- Contact page.
- Event information page.
- Volunteer information page.
- Public service information page.

If you are interested, send one public URL you would like checked.

Thanks.
