## 4. Feature List

- Preliminary accessibility checks for user-provided HTML, text, or public URL.
- Markdown and JSON output.
- Config generation.
- Exit codes for pass, warning, and blocked results.
- Standard-library-only Python implementation.
- URL mode with timeout and byte limit.
- Stable rule IDs for findings.
- Location and short element hints where available.
- Remediation guidance per finding.
- Severity overrides through config.
- Markdown severity summary table.
- Human review checklist and automated-vs-human-review documentation.

## 5. New v0.1.2 Improvements

- Improved remediation text for every rule with more concrete, safer wording.
- Added explicit false-positive and context-dependent finding guidance.
- Expanded human review workflow docs.
- Added parser edge-case tests for malformed HTML, mixed-case attributes, and wrapped labels.
- Added nonprofit, school, and community example pages.
- Expanded severity override examples and cautions.

## 6. v0.1.1 Improvements

- Added `rule_id` to every finding.
- Added structured JSON `location` objects and Markdown location hints.
- Added short element summaries without including full page content.
- Added remediation text to every finding.
- Added `severity_overrides` support for `blocker`, `warning`, and `info`.
- Improved Markdown report readability with a summary table.
- Improved URL error handling for invalid URLs, HTTP errors, timeouts, and oversized responses.
- Added ARIA, keyboard-focus, image-heavy, and severity-override examples.
- Expanded tests from 15 to 32 unittest cases.
