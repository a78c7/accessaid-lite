# Strengthen Human Review Workflow

## Problem

Users may need a more concrete workflow after receiving automated findings.

## Proposed Change

Expand the human review checklist and pilot report template with practical steps for small teams.

## Acceptance Criteria

- Human review docs include keyboard, focus, screen reader sanity, color contrast, mobile zoom, and real user feedback.
- Docs avoid legal and medical advice.
- Docs reinforce that automated checks are preliminary.

## Tests

- Documentation-only change; run full unittest suite.

## Privacy/Security Impact

No analytics. No page-content upload. No cookies/tokens/keychain/password manager access. No login. No form submission.

## Accessibility Impact

Better workflow can help teams move from findings to practical improvements.

## Notes

This must not turn AccessAid Lite into a full WCAG audit. No legal or medical advice.
