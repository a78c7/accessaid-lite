# Add Nonprofit And School Example Pack

## Problem

The examples are useful, but more realistic nonprofit and school pages could make the tool easier to understand.

## Proposed Change

Add local example pages for donation information, event signup information, school program pages, and open-source documentation.

## Acceptance Criteria

- Examples are local static HTML.
- Examples avoid real personal data.
- Examples do not include payment/KYC/withdrawal flows.
- Each example has expected findings documented.

## Tests

- Add smoke tests for representative examples.
- Keep tests local and deterministic.

## Privacy/Security Impact

No analytics. No page-content upload. No cookies/tokens/keychain/password manager access. No login. No form submission.

## Accessibility Impact

More realistic examples should help maintainers learn how to interpret reports.

## Notes

This must not turn AccessAid Lite into a full WCAG audit. No legal or medical advice.
